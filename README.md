# game_shooting_range

# Кейс - игра “Тир” с использованием Git и Pygame
https://github.com/Sophiya-ai/game_shooting_range
## 6 веток:
* **Main** - основа для игры
* **part-const-code** – ветка с константами
* **part-cycle-code** – ветка цикла
* **adition-scoreboard** – ветка разработки вывода по нажатию ПРОБЕЛа попаданий и промахов с выдачей звука поражения или фейерверка при выигрыше или ничьей
* **adition_shoot-sound** – ветка разработки выдачи звука выстрела
* **moving_target** – ветка разработки движущейся мишени

Последовательно ветки сливались с главной, и разрешались конфликты
